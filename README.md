# Nivelo

Aplicativo Android desenvolvido para projeto da faculdade.

## 📱 Sobre o Projeto

Nivelo é um aplicativo Android criado como trabalho acadêmico.

## 🛠️ Tecnologias Utilizadas

- Android Studio
- Kotlin (ou Java)
- Gradle

## 📋 Pré-requisitos

- Android Studio instalado
- SDK do Android (mínimo API 21)
- Git instalado

## 🚀 Como Usar

### Clonar o repositório

```bash
git clone https://github.com/wiltontargino/nivelo.git
cd nivelo
```

### Abrir no Android Studio

1. Abra o Android Studio
2. Clique em "Open an Existing Project"
3. Selecione a pasta `nivelo` que você clonou
4. Aguarde o Gradle sincronizar

### Executar o aplicativo

1. Conecte um dispositivo Android ou abra um emulador
2. Clique em "Run" (ícone de play) ou pressione `Shift + F10`
